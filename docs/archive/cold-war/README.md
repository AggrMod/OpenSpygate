# Archive: the Cold War proposal

Kept for the record. **This is not the plan.**

Until 2026-11-14 OpenSpygate was planned as a Cold War espionage game that began in Berlin in 1961. On that date the project lead changed the direction: OpenSpygate is now a modern-day, open-world city game set in a fictional present-day city. See `AGENTS.md` and `docs/GDD.md` for the game as it is now.

The documents below were written for the old direction. They are kept unchanged so the work and its sources are not lost. Do not build from them, and do not take them as the story or the setting of the game. The premise of the new game is the project lead's call and is still open.

| File | What it was |
|---|---|
| `STORY.md` | Story proposal, "The Legend": one real thread of spycraft from 1962 to the present day. Never approved |
| `design/recruitment.md` | Draft design for recruiting and running sources (task #4). Never reviewed to a decision |
| `reference/berlin/README.md` | Link-only reference pack for Berlin 1961 to 1963 (task #7). No images stored |

The opening door was designed from Berlin flat doors of about 1900 and is still in the game. Its specification lives in `docs/ART-BIBLE.md`, section 11, not here.
