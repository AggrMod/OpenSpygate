# Berlin 1961 to 1963: reference pack (links only)

Reference only. Nothing here is copied into the game. These are links for artists to look at while modelling. No image files are stored in this repository. No real brands are reproduced, and no real people's names are used on signs or plates. Where a photo shows real people, they are not to be recreated as likenesses.

Every item below was checked the same way: the page was opened and its licence line was read. Items whose licence could not be confirmed were left out. Licence text is quoted as the page gives it, using the legend in the last section.

Dates are the dates the page gives. Photo years and subject years differ for some items; the note says which.
